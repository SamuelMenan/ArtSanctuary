# Reglas de Agente para ArtSanctuary

Estas reglas aplican globalmente a cualquier agente o MCP que interactúe con el repositorio.

## REGLA PRINCIPAL DE DOCUMENTACIÓN (Obligatorio)

Nunca leas la carpeta `docs/` completa ni pidas todo su contenido. Sigue estrictamente este flujo antes de empezar cualquier tarea o leer cualquier otro documento:

1. Primero consulta `docs/AI_CONTEXT.md` para entender de qué trata el proyecto y su arquitectura base a alto nivel.
2. Luego consulta `docs/INDEX.md` para encontrar el mapa de todas las características y documentación.
3. Después identifica el dominio y la documentación específica relacionada con la tarea a realizar.
4. Abre únicamente los documentos de `docs/` que el índice te indique y que sean estrictamente necesarios usando las herramientas del MCP (ej. `read_file`).
5. Evita cargar documentación irrelevante al contexto.
