# ArtSanctuary

> Plataforma social artística. Prototipo. Pasto, Nariño, Colombia.

ArtSanctuary es una plataforma integral para artistas que combina herramientas de estudio (tableros, cuadrículas de referencia, recorte) con funciones sociales (perfiles, colecciones, seguimiento).

## Inicio Rápido

```bash
# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env.local

# Iniciar servidor de desarrollo
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Tecnologías Principales

- **Framework**: Next.js (App Router)
- **UI**: React, Tailwind CSS
- **Herramientas de Dibujo/Canvas**: Konva.js
- **Base de Datos**: MongoDB (Mongoose)
- **Autenticación**: NextAuth.js
